# Folder Tangkapan Layar (Screenshots)

Simpan file tangkapan layar antarmuka web CineMetrics di folder ini dengan nama-nama berikut:
1. `dashboard-simulator.png` -> Halaman simulator utama (slider dan hasil estimasi rating).
2. `riwayat-prediksi.png`   -> Halaman riwayat simulasi dan data SQLite.
3. `cinebot-chat.png`       -> Ruang percakapan asisten CineBot.
4. `about-identitas.png`     -> Halaman About dan identitas mahasiswa.

File-file gambar di atas akan otomatis ditampilkan di berkas README.md utama repositori GitHub.
